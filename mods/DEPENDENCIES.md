# Dependencies

The default `core` profile currently has no Workshop dependency chain beyond the listed item itself.

Compatibility constraints recorded from upstream:

- `DynamicEvolutionZ` must not be combined with Wandering, Starving, or Thump with Friends without a new review.
- `TheyFearTheLight` has no stated additional dependency, but is currently on hold for B42.20 verification.
- `TheDarknessIsComing` required Monkey's Library but is rejected for this Build 42.20 project.
