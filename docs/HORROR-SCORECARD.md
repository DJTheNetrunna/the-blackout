# Horror Scorecard

Target: **9.5/10 fear with cheap frustration at 5/10 or lower.** Scores remain provisional until the current B42.20.x build completes the live test matrix.

| Dimension | Design target | Runtime status |
|---|---:|---|
| Isolation | 9.5 | NOT_RUN |
| Uncertainty | 9.5 | NOT_RUN |
| Darkness | 9.5 | NOT_RUN |
| Unreliable information | 9.0 | NOT_RUN |
| Sound tension | 9.5 | NOT_RUN |
| Interior hesitation | 9.5 | NOT_RUN |
| Night travel fear | 9.5 | NOT_RUN |
| False security | 9.0 | NOT_RUN |
| Calm-to-crisis contrast | 9.0 | NOT_RUN |
| Cheap frustration | ≤5.0 | NOT_RUN |

## Pass criteria

- Players hesitate because they lack reliable information, not because enemy health is inflated.
- At least one uneventful calm period makes the next warning more effective.
- Rare speed changes remain surprising; they do not become the baseline.
- Night travel is possible with planning but feels meaningfully unsafe.
- Returning to a cleared location does not feel perfectly predictable.
- Audio cues matter without becoming constant, deafening, or obviously random spam.
- Failure can be explained after the fact and suggests a different decision next time.

Results must record build number, profile, mod versions, hardware, test duration, and whether the world saved/reloaded cleanly.
