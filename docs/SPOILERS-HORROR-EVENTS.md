# Knox Nightmare Horror Systems — Spoilers

> **Stop here if this is your first BLIND playthrough.** This document names threats, exact tuning, and systems that the normal player documentation intentionally leaves uncertain.

## Stable BLIND / SOLO stack

The default local stack uses one primary system per fear dimension instead of stacking multiple mods that rewrite the same behavior:

1. Starlit Library
2. DEZ — Dynamic Evolution Z
3. LED Lantern
4. Surviving the Storm
5. Reactive Sound Events
6. Bleak World - Horror
7. Special Zombies Framework
8. Special Zombies #01 — Screamer
9. Hark's Horde Night Revamped
10. Zombies Crash Through Windows

BLIND and SOLO deliberately use the same approved Workshop set. BLIND changes navigation by disabling both minimap and world map, and it keeps the first-playthrough instructions spoiler-free.

## Exact shared pressure

- random-speed zombies with rare sprinters: BLIND/SOLO 5%, CO-OP 4%, SERVER 3%;
- full activity concentrated at night;
- sound-following distance 225 and attraction multiplier 1.30;
- BLIND/SOLO population 1.10 with a 1.45 peak on day 21;
- frequent six-hour migration;
- long pitch-black nights;
- no loot respawn, very scarce medicine, firearms, ammunition, tools, fuel, and reliable vehicles;
- opening-weeks water/electricity failure pressure;
- no multi-hit or starter kit.

## Disclosed incidents

- some infected can break the expectation that a closed window ends pursuit;
- a rare special infected can turn one local mistake into a wider sound problem;
- weather can force shelter, reduce information, and make travel decisions worse;
- physical and audio scenes can wake or panic the player and can be heard by nearby infected;
- periodic horde pressure prevents a cleared base from becoming a permanent end state;
- the evolution layer changes the world and infected pressure over time instead of preserving a fixed opening-week pattern.

## Stable-first candidates — not enabled

These are tested one at a time on disposable worlds. They are not part of BLIND:

- **Hibernating Zombies:** dormant infected and false corpses; single-player candidate, multiplayer work in progress.
- **Reanimating Zombies:** delayed/progressive corpse reanimation; needs current B42.20 validation.
- **They Fear the Light:** dynamic light/night behavior; official DEZ compatibility exists, but current audio/night-state reports require live testing.
- **Knox Acoustics + ZombieBuddy:** physically modeled acoustics; pre-release, extra setup, and higher CPU cost.
- **Occult Zombies:** alternate special-infected layer; must be checked against visual/spawn systems.
- **Projeto Nemesis:** stalker/boss pressure; must be proven fair, rare, and persistent without becoming repetitive.

Starving Zombies is rejected despite its strong corpse-scent concept because it conflicts with the default DEZ behavior authority.

## Player-facing disclosure rule

Public announcements may reveal the pillars—darkness, sound, unstable safety, weather, scarcity, and changing behavior—but should not publish exact event clocks, spawn triggers, safe-zone rules, or a complete special-threat catalogue. Technical disclosure remains available here for informed consent, troubleshooting, accessibility, and modpack development.
