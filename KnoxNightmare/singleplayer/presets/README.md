# SOLO preset

The installable Build 42 `.cfg` is generated from:

```text
config/sandbox/base.cfg
+ config/profiles/solo.cfg
```

Run `scripts/configure-knox.sh solo`. The result is `.generated/solo/Knox Nightmare - SOLO.cfg`, and `scripts/install-local.sh solo` installs that file into the detected Project Zomboid `Sandbox Presets` directory.
