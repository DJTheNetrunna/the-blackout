# Knox Nightmare Profile

This directory records the game-design layer separately from Linux deployment automation.

The canonical production baseline is:

- Project Zomboid Build 42.20.x
- long, pitch-black nights
- sprinter speed while zombies are active
- zombies fully active at night
- elevated Build 42 population curve
- recurring migration/respawn pressure
- long sound attraction distance
- no minimap
- no multi-hit
- approved mod profile generated from `mods/manifest.tsv`
